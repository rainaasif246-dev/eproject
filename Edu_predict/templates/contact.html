FAQ
Frequently Asked Questions
Quick answers to common questions about EduPredict.
What is EduPredict? +
EduPredict is an AI-powered student performance and dropout prediction system built on Hadoop Big Data and Machine Learning (Random Forest, XGBoost).
Do I need a Hadoop cluster to run it? +
No. Hadoop and HDFS are simulated within the Flask app for demonstration purposes. No actual Hadoop cluster is required to run the project.
What user roles are available? +
EduPredict supports 4 roles: Administrator, Teacher, Analyst, and Student — each with role-based access control (RBAC) as defined in the SRS.
How accurate are the ML predictions? +
The Dropout Risk Classifier achieves 93.4% accuracy with a ROC-AUC of 0.965. The Academic Performance Predictor achieves 89.7% accuracy.
How do I get started? +
Install dependencies with pip install -r requirements.txt, then run python app.py and open http://127.0.0.1:5000.
