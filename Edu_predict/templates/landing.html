About EduPredict
Built for the future of education

EduPredict is an AI-powered analytics platform that helps institutions make data-driven decisions. Hadoop distributed computing + machine learning turns raw student data into actionable insights.

From predicting exam scores to detecting at-risk students before they drop out — EduPredict empowers every stakeholder.

Features
Everything you need to manage student success
Built on SRS requirements — from data ingestion to real-time alerts, all in one platform.
🤖
ML Prediction Engine
Random Forest predicts exam scores and at-risk students using 21 real features from Student Performance Dataset.
📊
Analytics Dashboard
Interactive Chart.js visualizations — score distribution, risk breakdown, attendance vs performance trends.
🔔
Automated Alerts
Configurable thresholds trigger real-time notifications for low attendance, score risk, and dropout anomalies.
🗄️
HDFS Data Storage
Hadoop Distributed File System with 3× replication, 4 active DataNodes, and 2.4TB scalable storage.
⚡
Real-Time Processing
Apache Kafka + Spark Streaming pipeline processing 1,247 events/sec with 12ms latency.
🔐
Role-Based Access Control
SHA-256 secured authentication with 4 roles — Administrator, Teacher, Analyst, Student.
📥
Data Ingestion Pipeline
Upload CSV, JSON, XML datasets — Academic Records, Demographics, LMS Activity — into HDFS pipeline.
📚
Course Demand Forecast
Predict future enrollment demand by course category with growth trend analysis and faculty recommendations.
💬
Support Portal
Full ticket system with category, priority, history tracking, FAQ accordion, and multi-channel contact support.
