# EduPredict — Test Data Documentation

## 1. Dataset Overview

| Property | Value |
|---|---|
| Total Records | 2,000 synthetic student records |
| Train Split | 1,600 records (80%) |
| Test Split | 400 records (20%) |
| Random Seed | 42 (reproducible) |
| Generated By | `train_models.py` |

---

## 2. Feature Description

| Feature | Type | Range | Description |
|---|---|---|---|
| `hours_studied` | Float | 1.0 – 40.0 | Weekly study hours per student |
| `attendance` | Float | 40.0 – 100.0 | Attendance percentage |
| `previous_scores` | Float | 30.0 – 100.0 | Previous semester exam score |
| `parental_involvement` | Integer | 0, 1, 2 | 0=Low, 1=Medium, 2=High |
| `tutoring_sessions` | Integer | 0 – 9 | Number of tutoring sessions attended |

---

## 3. Target Variable

| Variable | Type | Range | Formula |
|---|---|---|---|
| `exam_score` | Float | 0 – 100 | `0.35×prev_scores + 0.25×attendance + 0.20×hours + 3.0×parental + 1.5×tutoring + noise(0,4)` |
